# CareBloomOS integration example

CareBloomOS was Journey's first mature expression profile. It demonstrates how
an external project can translate stable functional kernels into domain-specific
language while Journey keeps the underlying contracts and safety behavior
unchanged.

| Journey kernel | CareBloom translation |
|---|---|
| integrate | Corestone / Opalstone |
| sustain | Heartstone |
| perceive | Moonstone |
| maintain | Cloverstone |
| regulate | Cloudstone |
| route | Wishstone |
| synchronize | Musicstone |

This example documents the mapping only. CareBloomOS artwork, icon decisions,
canon, handoffs and project-only operational scripts remain with CareBloomOS and
are intentionally excluded from the Journey repository.
