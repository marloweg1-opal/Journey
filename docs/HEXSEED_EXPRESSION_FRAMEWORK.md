# Expression Framework

Journey separates stable system meaning from project-specific presentation.

## Stable layer

The functional kernels are:

- integrate
- sustain
- perceive
- maintain
- regulate
- route
- synchronize

Authority, system state, receipts, provenance and rollback behavior remain stable
regardless of the active profile.

## Project-owned profiles

An external project may translate kernel names, colors, icons, sound, motion and
interface language. That profile remains owned by the external project and must
not become Journey's base ontology.

Journey stores only the contract and the smallest example needed to verify that
translation. See [Project Boundaries](PROJECT_BOUNDARIES.md).
